# 🔍 ResearchMate AI

An AI-powered research assistant that helps users explore topics, search the web and generate structured research reports.

## 🚀 Features

* Web search using DuckDuckGo
* AI-powered research report generation using Groq
* Structured research reports
* Download reports as PDF
* Save and view previous research history
* Clean and user-friendly interface built with Streamlit

## 🛠️ Technologies Used

* Python
* Streamlit
* Groq API
* DuckDuckGo Search
* ReportLab

## 📸 Application Overview

ResearchMate AI provides a simple interface where users can enter a research topic and receive an AI-generated report with relevant web sources.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/manthanpalande0001-lang/ResearchMate-AI.git
```

### 2. Open the project folder

```bash
cd ResearchMate-AI
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment

Windows:

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure your API key

Create a `.env` file in the project folder:

```text
GROQ_API_KEY=your_groq_api_key
```

Replace the placeholder with your own Groq API key. Never share your API key publicly.

### 7. Run the application

```bash
streamlit run app.py
```

## 🎯 Project Objective

The objective of ResearchMate AI is to simplify online research by combining web search and artificial intelligence to generate organized research reports.
